## 🇷🇺 О проекте

**SCHOOL CALC** — калькулятор школьных оценок, созданный German в рамках **GERMAN'$ CODE TEAM**. Считает средний балл и помогает следить за успеваемостью без аккаунта и облачного профиля.

### Возможности

- Средний балл обновляется сразу после изменения списка оценок.
- Шкалы оценивания: 5, 10 и 12 баллов.
- Удаление отдельных оценок или очистка всего списка.
- Оценки существуют только в текущем сеансе и не сохраняются после перезагрузки страницы.
- Настройки интерфейса сохраняются в браузере.
- Светлая и тёмная темы, пять цветовых акцентов.
- Русский и английский интерфейс.
- Гера — помощник с реакциями на текущий результат.
- Объявление на сайте задаётся через `event.txt`.
- Адаптивная вёрстка для телефона и компьютера.

Расчёт использует обычное арифметическое среднее. Если оценки в школе имеют разный вес, результат может отличаться от официального.

### Приватность

Оценки не записываются в `localStorage` и исчезают после перезагрузки страницы. В `localStorage` сохраняются только настройки интерфейса. Приложению не нужен аккаунт.

## 🧑‍💻 Для разработчиков

### Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Основная HTML-страница |
| `style.css` | Стили и темы |
| `script.js` | Логика и обработчики интерфейса |
| `src/grade-engine.js` | Расчёты среднего балла и целей |
| `src/storage.js` | Сохранение и проверка состояния |
| `src/App.vue` | Исходный вариант разметки Vue; для запуска сайта не требуется |
| `event.txt` | Текст информационного блока |
| `.github/workflows/deploy.yml` | Проверка и публикация на GitHub Pages |

**Сайт работает без Vite, Vue runtime и npm-пакетов.** GitHub Actions копирует статические файлы и публикует их на GitHub Pages.

### Локальный запуск

Нужен современный браузер. Из-за JavaScript-модулей лучше запускать через локальный сервер, например расширение Live Server в VS Code.

#### Публикация

Изменения в ветке `main` автоматически запускают GitHub Actions. Статические файлы отправляются на GitHub Pages.
